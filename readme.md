# E-Commerce Store

## Description
A terminal-based E-Commerce Store built using Python and Object-Oriented Programming. Users can browse available products, add them to their cart, remove products, and calculate the total cost.

## Features
- Browse available products and their stock.
- Add products to the cart.
- Add more quantities of an existing cart product.
- Remove products from the cart.
- Automatically update inventory stock.
- Calculate the total cart cost.
- Validate quantity input and check stock availability.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## How to Run
Make sure Python is installed on your computer.

Open a terminal in the project folder and run:

`python main.py`
